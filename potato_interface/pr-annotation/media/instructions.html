Annotation Guidelines

Do the code changes of the pull request match its title and description?

How to annotate (step by step)

  1. Open the PR link. If the PR is not available, mark it as Unavailable.
  2. Read the title and description.
  3. If the PR is not an extract/move method, extract class, extract/move field or refactor, mark it as Out of scope.
  4. Check each line in the description against the code changes.
  5. If all lines are found in the code changes, mark the PR as Consistent.
  6. If any line is not found in the code changes, mark the PR as Inconsistent.

Labels

LabelWhen to use it
ConsistentAll bullet points in the description are found in the code changes.
InconsistentAt least one bullet point in the description is not found in the code changes.
UnavailableThe PR is not available.
Out of scopeThe PR is not an extract/move method, extract class, extract/move field or refactor.
